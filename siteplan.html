Guitar & Piano Learning Hub

A beginner-friendly guide to learning guitar and piano, building a practice habit, and finding a first musical goal.

Site name and reason

Guitar & Piano Learning Hub names the two instruments covered and describes the site as a welcoming starting point for beginners. “Learning Hub” signals that learners can find chords, practice guidance and instrument information in one place.

Site purpose and audience

The site organizes useful beginner resources in one place: first chords and notes, practice tips, and information to help new musicians choose an instrument. It aims to make learning music accessible, encouraging and engaging.

Target audience: Beginners who are curious about guitar or piano, including learners choosing their first instrument.

Audience scenarios

  • What are a few easy chords I can learn first?
  • How should I plan a short, useful practice session?
  • Should I begin with guitar or piano?

Color scheme

The document and project use a calm, welcoming music-workbook palette. Midnight provides contrast, warm paper softens reading surfaces, coral highlights actions, and teal identifies learning tips.

Typography

Fraunces is used for the site name and section headings to give the plan a friendly, expressive character. DM Sans is used for paragraphs, labels and interface text for clear reading. Both typefaces are applied in this document as well as in the project.

Project pages and interactions

The three pages are Home; Chords & Notes, with a searchable guitar and piano reference; and Practice & Instruments, with an instrument comparison, practice routine, timer and goal form.

  • Fetch at least 15 chord and note references from local JSON data, showing multiple details for each item.
  • Filter and search references, open an accessible details dialog, and save favorites with local storage.
  • Use a JavaScript practice timer and save a practice goal on the learner's device.
  • Use a GET form and display submitted fields on a separate action page.
  • Organize JavaScript with ES modules, Fetch, asynchronous error handling, template literals, DOM updates and array methods.
